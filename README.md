# HEOA 健康服务与产业组织研究智库

以专业研究服务健康中国建设，以真实证据支持健康服务优化、产业发展与公共治理。

本仓库保存 HEOA 网站 V24 的源码、内容与静态预览版本。网站汇聚公共卫生、医学、经济学、管理学与地理科学领域的研究动态，同时展示健康城市发展研究中心、团队成员和相关专题平台。

## 在线访问

- **正式网站：<https://heoagroup.org/>**，无需登录。
- GitHub Pages 原地址：<https://bayesianstvc.github.io/HEOA/>，自动跳转至正式域名。
- 离线包与版本记录：[GitHub Releases](https://github.com/bayesianstvc/HEOA/releases)。

正式域名已绑定本仓库的 GitHub Pages，发布目录为 `pages/`。文章中的外部个人主页、合作机构和专题平台链接仍访问各自网站。

## 仓库结构

```text
source/                 V24 应用源码、内容 JSON、当前媒体素材与依赖锁文件
pages/                  GitHub Pages 静态网站
scripts/                静态导出、核查和本地预览工具
docs/                   发布说明、体积审计与许可说明
.github/workflows/      GitHub Pages 发布流程
LICENSE                 PolyForm Strict 1.0.0 官方许可原文
NOTICE                  权利归属与第三方内容声明
```

应用源码使用 React、TypeScript 和 Vinext。GitHub Pages 使用预渲染 HTML、CSS 和轻量 JavaScript，当前正式域名从 `/` 根路径提供内容，不依赖服务器端 Worker 执行。导出工具支持显式指定根路径或项目子路径；发布前自动核对导出地址与 GitHub Pages 实际配置，避免域名切换后样式和图片失效。

## 离线浏览与开发

下载 Release 中的离线预览包并解压。已安装 Node.js 时，Windows 可双击 `预览网站.cmd`；其他系统可在解压目录运行：

```sh
node scripts/serve-pages.mjs
```

当前仓库访问 <http://127.0.0.1:4173/>；先前 `v24-github-20260909` 离线包仍使用 <http://127.0.0.1:4173/HEOA/>。预览工具会读取相应导出版本的路径。预览不需要安装 npm 依赖。正文、本站图片及成员资料可以离线查看；访问外部网站仍需要网络。不要直接双击 HTML 文件作为完整功能验证方式。

开发源码需要 Node.js 22.13 或更新版本：

```sh
cd source
npm ci
npm run dev:local
```

首次安装依赖需要网络。仓库保留 `package-lock.json`，不重复上传可重新安装的 `node_modules`。源码开发服务与静态预览服务是两个不同入口。

## 图片与备份策略

- 成员照片保持自然比例与合理留白；网页图片以清晰、轻量为目标，优先使用 WebP。
- 文章插图和资料图优先保持文字可读性，不为压缩率反复进行有损转码。
- 字节相同的素材共用文件；静态镜像只携带完整网站实际需要的资源。
- 源码和内容可在仓库查看；离线包提供完整的公开网站浏览内容。
- 本地原始恢复包及历史高清原图继续保留，不将开发依赖、重复发布目录与处理临时文件混入访客预览包。

本次静态镜像约 **71.0 MB**，其中媒体约 **57.4 MB**。无损整理后重复媒体为零，全部 1,657 个本地链接通过文件存在与子路径检查；图片没有再次有损转码。详细依据见 [来源与体积审计](docs/来源与体积审计.md) 和 [静态导出说明](docs/静态导出说明.md)。

该镜像来自 V24 应用源码提交 `dde91574c5a6a3686e5fb9513a0e4147cea8af79`。具体文件数量、大小、校验值与验证结果见发布说明。

# HEOA GitHub Pages 静态导出

仓库静态网站位于 `pages/`。它由源站 React 页面和组件预渲染，保留原站已编译 CSS，核心交互改由 9 KB 级别原生浏览器脚本处理；没有 Worker、RSC、React hydration 或 Sites API 运行依赖。

## 可复现入口

```powershell
node scripts/export-pages.cjs <V24应用目录> <全新输出目录> / https://heoagroup.org
```

导出器需要源站本地安装的 `react`、`react-dom`、`typescript`，以及源站构建生成的 `dist/client/_next/static/css/` 和 `sites-public-v24-web-release/`。先在源站运行其既有构建流程，再运行导出。脚本只读取源站，不修改其代码或构建目录。为保留检查点，已有输出目录会被拒绝覆盖。

归档中同时保留 `export-pages.cjs`、`deployment-config.cjs`、`pages-runtime.js` 和 `wechat-7204-icon.png` 四个复现输入。后者是原文唯一远端装饰图片（微信公开资源，14×23 PNG，207 字节）的字节保持副本，不需要每次联网下载。

## 完成范围

- 310 业务页面：299 篇内容详情、主站及健康城市中心入口、关于页面静态跳转。
- 另有 404 与历史资料引用说明页面，总 312 HTML。
- 全部站内 URL 按导出路径生成；当前自定义域名使用 `/`，旧项目预览可显式传入 `/HEOA/ https://bayesianstvc.github.io`。恢复 1,360 处原备份中数字 HTML 文件名／跨目录文章链接。
- 正文、附件、头像和品牌图从发布媒体中按实际引用收集，零缺失，不复制无引用的安全压缩镜像或运行依赖。
- 去重前 1,677 文件，73,888,623 字节；媒体 60,288,231 字节。1,333 张发布图片中最大 237,774 字节；另补 207 字节原微信装饰 PNG。普通文章图表没有再次有损压缩。
- 页面无远端 `img`、`script`、`iframe` 加载依赖；外部个人主页、机构链接与 Google 翻译保留原用途。

`heoa-post-7772` 的图 5 在原始正文中已错误引用 `../../../recovery/unmatched-source-reference.html`，原备份缺少图像。导出时替换为明确说明“原始备份中的该幅图像暂缺”的 SVG，占位不会虚构数据，原文和图注完整保留。赖泓宇头像也沿用源站“头像待补充”。

## 功能边界

本静态版支持阅读、筛选、搜索、翻页、轮播、导航与附件下载；不提供服务器写入接口。原站同样没有实现的后台接口不被伪装成可用功能。外部个人主页、机构网站和在线翻译仍需互联网。

## 无损优化与发布

预渲染输出经过 `scripts/optimize-pages.mjs` 无损去重后放入 `pages/`。发布目录共 1,678 个文件、71,019,560 字节，其中媒体 57,408,473 字节；同字节重复媒体为 0。保留图片逐字节核对不变。去重后的 1,657 个本地 URL 再次检查通过，无缺失或子路径越界。

推送 `main` 后，由 `.github/workflows/pages.yml` 上传 `pages/` 并部署 GitHub Pages。复现时请为导出器及优化器分别指定新的输出目录，验收后再更新发布目录，保留旧版本用于回退。
